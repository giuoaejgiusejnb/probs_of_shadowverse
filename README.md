# Shadowverse確率計算Webページ

対戦型カードゲーム「Shadowverse」のランダムダメージによるリーサル確率と、一定試合数の間に目標連勝数を達成する確率を計算するWebページです。

**公開ページ：** https://giuoaejgiusejnb.github.io/probs_of_shadowverse/

## 開発背景

対戦中の盤面や自分の勝率から必要な確率を手軽に確認できるようにするため、趣味の個人開発として制作しました。企画・設計・実装・公開まで一人で行っています。

## 機能

### サンダルフォンのリーサル確率

相手リーダーとフォロワーの体力を入力し、2ダメージを5回ランダムに与えたとき、相手リーダーを倒せる確率を計算します。

### オルオーンのリーサル確率

自分・相手リーダーとフォロワーの体力を入力し、7ダメージを3回ランダムに与えたとき、自分または相手のリーダーが倒される確率をそれぞれ計算します。

### 連勝確率

1試合ごとの勝率、試合数、目標連勝数を入力し、その試合数の間に目標以上の連勝を一度でも達成する確率を計算します。

## 技術的な工夫

### 途中で変化する抽選対象を反映

ランダムダメージでは、途中でフォロワーが倒れると、その後のダメージの抽選対象から外れます。また、リーダーが倒れた場合は、その時点で残りのダメージ処理が終了します。

そこで、ダメージの当たり方を列挙したうえで、ダメージを与えるたびに各対象の体力と残っている対象数を更新し、実際のゲームルールに沿って各経路の確率を計算しています。

### 入力規模に応じた連勝確率の計算

連勝確率は、試合数を `n`、目標連勝数を `k` としたとき、動的計画法ではおおむね `O(n)`、行列累乗では `O(k³ log n)` で計算します。

入力された試合数と目標連勝数から計算量を比較し、小規模な入力では動的計画法、試合数が大きい場合は行列累乗を使用することで、入力規模に応じて計算量を抑えています。

## ローカルでの実行方法

このリポジトリをクローンし、ローカルサーバーを起動します。

```bash
git clone https://github.com/giuoaejgiusejnb/probs_of_shadowverse.git
cd probs_of_shadowverse
python -m http.server 8000
```

起動後、ブラウザで http://localhost:8000/ を開いてください。インストール不要で確認する場合は、上記の公開ページをご利用ください。
